# Impeccable audit of DeepSignal Console v2

Impeccable 4.8.0 ran offline with telemetry disabled. The checker scanned local HTML snapshots generated by executing the built inline boot script and JavaScript against the shipped YAML in jsdom, with the built CSS embedded. The snapshots used simulated cache replies and a canvas test double.

| Mode | Main page findings | Checker exit |
| --- | --- | --- |
| Day | 0 | 0 |
| Dusk | 0 | 0 |
| Night red, 80% | 11 low-contrast warnings | 2 |
| Night neutral, 80% | 0 | 0 |

The two Night palettes also ran through loading, invalid console settings, an invalid page file, and reconnecting. Night neutral had zero warnings. Night red had 5, 5, 10, and 11 low-contrast warnings respectively. All eight snapshots retained the black boot background and their stored Night palette.

## Fixed

- Raised the Night default from 60% to 80%. The checker now reports about 3.6:1 for primary red text on black, above its 3:1 threshold for the 48 px reading.
- Applied the foreground token to reconnect text and to the age and last-reading details for non-live readings. Increased tile labels to 20 px and metadata to 16 px.
- Kept Night tiles on the black canvas with borders for separation. Red channel scaling leaves headroom below the 15% green and blue limit for antialiased edges.

## Retained and pending

- **P1, Night red contrast.** Normal-size text at 80% is below the checker's 4.5:1 target. Muted text is about 1.8:1. Retained the rulebook's dimmer range, red pixel limit, and muted normal states. Night neutral had zero findings at its default.
- Chromium could not launch in the sandbox because macOS denied its Mach port bootstrap. The lead's live browser run covers rendered red pixels and the first reload frame. Display luminance and viewing distance remain part of the onboard release gate.
